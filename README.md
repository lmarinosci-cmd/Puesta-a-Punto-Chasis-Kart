# Planilla de Chasis

App web para la puesta a punto del chasis de karting:

- **Diagnóstico:** elegís qué hace el kart y te da los ajustes recomendados, ordenados según lo que funcionó en tus salidas.
- **Setup:** simulador con barras y el kart dibujado en tres vistas.
- **Salidas:** registro de cada tanda con vuelta, sensación, cambio y resultado.
- **Telemetría:** lectura de CSV exportados de AiM Race Studio (MyChron 5S).

Es un solo archivo, `index.html`. Se abre en cualquier navegador.

Fuera de claude.ai los datos se guardan en el navegador de cada dispositivo, y la pestaña Ingeniero no funciona.
